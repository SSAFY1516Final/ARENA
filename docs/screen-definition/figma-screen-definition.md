# Figma 화면정의서

## Figma Slides 산출물

- 제목: ARENA(아레나) 화면정의서
- 형식: Figma Slides 화면정의서 덱
- 생성 방식: Codex의 Figma Slides 생성 위젯
- 비고: 채팅 UI에 표시된 Figma Slides 미리보기 중 하나를 선택하면 Figma에서 열고 편집할 수 있습니다.

## 초안 디자인 파일

- URL: https://www.figma.com/design/D2K8zIoLfbaGbdpdIfdAh2
- 비고: 설정 과정에서 생성한 초안 파일입니다. 주 산출물은 Figma Slides로 생성된 화면정의서 덱입니다.

## 포함 화면

- 00. 화면정의서 개요
- 01. 홈 / 토론 생성
- 02. 회원가입 / 로그인
- 03. 토론방
- 04. 토론 종료 / 요약
- 05. 게시판 목록 / 검색 / 필터
- 06. 게시글 상세 / 투표 / 댓글

## 정의 범위

각 화면 프레임에는 다음 내용을 포함했습니다.

- 화면 목적
- 주요 사용자 입력
- 주요 액션
- 연동되는 Spring Boot API
- 검증 및 예외 상태
- 대표 와이어프레임

## 현재 요구사항 반영 메모

- 프로젝트명은 `ARENA(아레나)`를 기준으로 사용합니다.
- 게시판 목록 화면은 키워드 검색, 토론 모드 필터, 최신순/댓글순/투표순 정렬을 포함해야 합니다.
- 게시글 상세 화면은 투표 선택지 A/B, 선택지별 투표 수, 투표 비율, 댓글 영역을 함께 보여줘야 합니다.
- 토론 종료/공유 화면은 게시글 제목과 투표 선택지 A/B 입력을 포함해야 합니다.
- API 문서 기준은 `docs/api/arena-rest-api.md`입니다.

## 비고

이 산출물은 최종 UI 디자인 시스템이 아니라 구현 전 화면정의서입니다. JSP, HTML, CSS, Vanilla JavaScript 기반 프론트엔드 구현을 위해 화면 책임, 데이터 흐름, API 경계를 명확히 하는 데 목적이 있습니다.
