# 화면정의서

## Figma Slides 산출물

- 제목: ARENA(아레나) 화면정의서
- 형식: Figma Slides 화면정의서 덱
- 생성 방식: Codex의 Figma Slides 생성 위젯
- 비고: 채팅 UI에 표시된 Figma Slides 미리보기 중 하나를 선택하면 Figma에서 열고 편집할 수 있습니다.

## 초안 디자인 파일

- URL: https://www.figma.com/design/D2K8zIoLfbaGbdpdIfdAh2
- 비고: 설정 과정에서 생성한 초안 파일입니다. 주 산출물은 Figma Slides로 생성된 화면정의서 덱입니다.

## 포함 화면

- 00. 화면정의서 개요
- 01. 카카오 로그인
- 02. 홈 / 후보 선택형 토론 생성
- 03. 토론방
- 04. 토론 종료 / 요약 / 공유
- 05. 내 토론 목록
- 06. 게시판 목록 / 검색 / 필터
- 07. 게시글 상세 / 투표 / 댓글
- 08. 관리자 / 사용자 권한 / 게시글 공개 관리

## 정의 범위

각 화면 프레임에는 다음 내용을 포함했습니다.

- 화면 목적
- 주요 사용자 입력
- 주요 액션
- 연동되는 Spring Boot API
- 검증 및 예외 상태
- 대표 와이어프레임

## 현재 요구사항 반영 메모

- 프로젝트명은 `ARENA(아레나)`를 기준으로 사용합니다.
- 인증 화면은 일반 회원가입/로그인이 아니라 Kakao OAuth 로그인 전용입니다.
- 카카오 콜백 화면은 authorization code를 백엔드 `/api/auth/kakao`로 전달하고 서비스 JWT를 저장합니다.
- 로그인 후 상단 프로필 칩에는 현재 닉네임이 표시되며, 사용자는 닉네임을 직접 수정할 수 있습니다.
- 홈 화면은 로그인 사용자가 토론 주제, 상황/조건, 세부 조건을 입력하고 검증 통과 후보를 선택해 토론을 생성하는 화면입니다.
- 홈 화면에는 후보 생성, 로컬 린트, 검증/정렬, 토론 생성 단계가 파이프라인 형태로 표시됩니다.
- 실용/예능 모드 선택 UI는 노출하지 않습니다. 현재 서버 호환을 위해 기본 모드는 내부값으로만 전송합니다.
- 게시판 목록 화면은 키워드 검색, 토론 모드 필터, 최신순/댓글순/투표순 정렬을 포함해야 합니다.
- 게시글 상세 화면은 투표 선택지 A/B, 선택지별 투표 수, 투표 비율, 댓글 영역을 함께 보여줘야 합니다.
- 토론 종료/공유 화면은 게시글 제목과 투표 선택지 A/B 입력을 포함해야 합니다.
- 관리자 화면은 사용자 권한 변경과 게시글 공개 여부 변경을 포함합니다.
- API 문서 기준은 `docs/deliverables/api/arena-rest-api.md`입니다.

## 비고

이 산출물은 최종 UI 디자인 시스템이 아니라 구현 전 화면정의서입니다. 현재 구현 기준 프론트엔드는 Vue 3, Vite, Pinia, Axios를 사용하며, 화면 책임, 데이터 흐름, API 경계를 명확히 하는 데 목적이 있습니다.

## 구현 화면 보정 메모

현재 Vue 구현 기준 `/new` 화면은 다음 영역으로 구성됩니다.

| 영역 | 설명 |
| --- | --- |
| 사용자 입력 | `토론 주제`, `상황/조건`, `세부 조건`을 입력합니다. |
| 파이프라인 상태 | 후보 생성, 로컬 린트, 검증/정렬, 토론 생성 단계를 순서대로 보여줍니다. |
| 검증 통과 후보 | 3개의 후보 카드와 참신도, 적합도, 토론성 점수를 표시합니다. |
| 선택 후보 미리보기 | 선택된 후보의 장면과 A/B 주장 요약을 보여줍니다. |
| 토론 시작 | 선택 후보 제목을 기존 토론 생성 API로 전송합니다. |
