# ARENA(아레나) 요구사항 정의서

## 1. 서비스 개요

ARENA(아레나)는 사용자의 선택 고민과 상상 논쟁을 두 AI 페르소나의 토론으로 풀어주는 웹 커뮤니티 서비스이다. 사용자는 카카오 계정으로 로그인하고, 토론 주제와 모드를 입력한 뒤 냉정파와 열정파가 번갈아 주장하는 과정을 확인한다. 원하는 시점에 토론을 멈추면 요약 결과를 게시판에 공유하고, 다른 사용자는 투표와 댓글로 의견을 남길 수 있다.

## 2. 프로젝트 목표

MVP 목표는 단순 AI 챗봇 데모가 아니라 카카오 OAuth 인증, JWT 기반 API 보호, AI 토론 생성, 게시판, 댓글, 투표가 연결된 웹서비스를 완성하는 것이다. Spring Boot 애플리케이션은 사용자와 서비스 데이터를 관리하고, Spring AI는 공통 호출 환경과 토론 발화/요약 생성의 기초 연동을 담당한다.

### 핵심 성공 기준

| --- | --- |

## 7. 상세 요구사항

### 7.1 인증/회원

- 사용자는 카카오 로그인으로 서비스에 진입한다.
- 프론트는 Kakao authorization code를 백엔드 `/api/auth/kakao`로 전달한다.
- 백엔드는 Kakao 사용자 정보를 조회하고, 기존 사용자가 없으면 `provider=KAKAO`, `provider_id` 기준으로 사용자를 생성한다.
- 카카오 사용자는 `password_hash`를 사용하지 않으므로 NULL을 허용한다.
- 로그인 성공 시 서비스 JWT access token을 발급한다.
- 인증이 필요한 API는 `Authorization: Bearer {accessToken}` 헤더를 사용한다.
- 로그아웃은 클라이언트가 저장된 JWT를 삭제하는 방식으로 처리한다.

### 7.2 토론

- 토론 생성 시 주제와 모드는 필수이다.
- 모드는 `PRACTICAL` 또는 `ENTERTAINMENT`만 허용한다.
- 생성된 토론의 초기 상태는 `ACTIVE`이다.
- 다음 턴 생성은 토론 작성자만 가능하다.
- 다음 턴 생성 시 Spring 서버가 기존 메시지 목록과 다음 라운드 번호를 AI 생성 계층에 전달한다.
- 토론 중단은 `ACTIVE` 상태에서만 가능하다.
- 토론 중단 시 상태를 `STOPPED`로 변경하고 요약을 저장한다.

### 7.3 게시글

- 게시글 공유는 `STOPPED` 상태 토론만 가능하다.
- 하나의 토론은 하나의 게시글로만 공유할 수 있다.
- 게시글은 제목, 요약 카드, 투표 선택지 A, 투표 선택지 B, 공개 여부를 가진다.
- 공개 게시글만 비회원 목록/상세 조회 대상이다.
- 작성자만 본인 게시글을 삭제할 수 있다.
- 관리자는 게시글 공개 여부를 변경할 수 있다.

### 7.4 투표

- 회원은 게시글의 선택지 A 또는 B 중 하나에 투표할 수 있다.
- 한 회원은 한 게시글에 하나의 투표만 가질 수 있다.
- 이미 투표한 사용자가 다시 투표하면 기존 투표 선택지를 변경한다.
- 게시글 목록과 상세는 선택지별 투표 수와 비율을 표시한다.
- 투표 비율은 전체 투표 수가 0이면 A/B 모두 0.0%로 표시한다.

### 7.5 검색 및 필터

- 게시글 목록은 제목, 요약 카드, 원본 토론 주제를 대상으로 키워드 검색을 제공한다.
- 토론 모드별 필터를 제공한다.
- 정렬 기준은 최신순, 댓글순, 투표순을 제공한다.
- 페이지 번호와 페이지 크기를 제공한다.

### 7.6 댓글

- 댓글 작성은 로그인 사용자만 가능하다.
- 댓글 삭제는 작성자만 가능하다.
- 댓글은 소프트 삭제를 사용해 `deleted_at`을 기록한다.
- 삭제된 댓글은 목록과 상세 응답에 노출하지 않는다.

### 7.7 관리자

- 관리자는 전체 사용자 목록을 조회할 수 있다.
- 관리자는 다른 사용자의 권한을 USER 또는 ADMIN으로 변경할 수 있다.
- 관리자는 게시글 공개 여부를 변경할 수 있다.

## 8. 주요 사용자 흐름

1. 사용자가 카카오 로그인으로 서비스 JWT를 발급받는다.
2. 홈 화면에서 토론 주제와 모드를 선택한다.
3. Spring 서버가 debate_sessions를 생성한다.
4. 사용자가 한 라운드 더 진행하면 Spring AI 연동 계층이 다음 발화를 생성한다.
5. Spring 서버가 AI 발화를 debate_messages에 저장한다.
6. 사용자가 토론을 멈추면 Spring 서버가 요약을 생성하고 저장한다.
7. 사용자가 요약을 게시판에 공유한다.
8. 다른 사용자가 검색/필터로 게시글을 탐색한다.
9. 다른 사용자가 게시글의 두 선택지 중 하나에 투표하고 비율을 확인한다.
10. 다른 사용자가 게시글 상세와 댓글을 확인한다.
11. 관리자는 필요한 경우 사용자 권한과 게시글 공개 여부를 조정한다.

## 10. 제외 범위

- 일반 ID/PW 회원가입 및 로컬 로그인 UI
- JPA 도입
- 사용자별 OpenAI API 키 입력
